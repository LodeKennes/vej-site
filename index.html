The contract

The decision layer
you own.

Define the outcomes. Ask independent questions. Use the probabilities in ordinary code.

01 / CHOICE

Choose among outcomes.

Name the options and describe what they mean. Vej returns a probability for each.

02 / NOUL

Assess a statement.

Ask whether a statement holds in the supplied state, with probabilities for true and false.

03 / SCORE

Evaluate a rubric.

Describe the levels. Vej assesses each level independently, normalizes the scores and computes the expected position in code.

State + question + outcome→Native scorer→Probabilities

Independent candidates are batched. The current checkpoint repeats state encoding; shared-state reuse remains experimental. No measured serving-speed claim.

Questions

Straight answers.

What Vej returns, how to run it, and what it does not claim.

What does Vej return?
A probability for each outcome you define, within each independent question. Choice picks among named outcomes, Noul assesses whether a statement holds, and Score rates described rubric levels; the expected position is computed in your code.
Can I run Vej on my own hardware?
Yes. Inference runs locally through Vej’s native loader on CPU or a compatible CUDA/ROCm GPU, and the checkpoint is about 3.6 GiB. Access to the weights is currently limited to authorized Hugging Face account members.
Is Vej open source?
Vej code and model adaptations are Apache-2.0. Source and weights are not yet publicly available. The Qwen base model and the original datasets keep their own terms.
How was Vej evaluated?
On 14,286 held-out test decisions: 76.60% exact accuracy overall, 89.22% on Choice, 91.71% on Noul and 51.62% on Score. The same test placed hosted Jev 1.13 at 71.76% with the documented rounding adjustment.
Is Vej production-ready?
No. Vej is a text-only research alpha. Score reliability and tool diagnostics remain weak, and probabilities are not permission to act. Keep execution behind your own policy checks.
What does “Noul” mean?
Noul is Vej’s name for the assess-a-statement question type. It returns probabilities for true and false. It is an intentional product term, not a spelling error.

Explore the alpha.

The checkpoint is published privately on Hugging Face. The model card, original data sources and evaluation evidence are open to read here.

The contract

The decision layer
you own.

Define the outcomes. Ask independent questions. Use the probabilities in ordinary code.

01 / CHOICE

Choose among outcomes.

Name the options and describe what they mean. Vej returns a probability for each.

02 / NOUL

Assess a statement.

Ask whether a statement holds in the supplied state, with probabilities for true and false.

03 / SCORE

Evaluate a rubric.

Describe the levels. Vej assesses each level independently, normalizes the scores and computes the expected position in code.

State + question + outcome→Native scorer→Probabilities

Independent candidates are batched. The current checkpoint repeats state encoding; shared-state reuse remains experimental. No measured serving-speed claim.

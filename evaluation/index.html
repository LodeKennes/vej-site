Score exact-level accuracy is 51.62%, against 48.44% for a post-hoc test-majority control that uses the test labels. These figures use temperature 1. The hosted API uses temperature 1.334. That scale does not make a stated probability a guaranteed frequency on a new workflow.

Pea and Jev on the same rows.

Jev is TypeSafe’s hosted decision model. Hosted Jev 1.13 scored these same rows with its documented rounding adjustment. The difference is 4.84 percentage points on this test. It does not establish general superiority, broader transfer or statistical significance.

Pea against Qwen models.

Prompted Qwen3.5-2B, Qwen3.5-4B and Qwen3.5-9B answered the same 14,286 decisions. The comparison was pre-registered before those models ran. Pea is ahead of each of them on exact accuracy, including Qwen3.5-9B.

Exact accuracy and log loss (NLL, lower is better). Invalid answers count as wrong. Qwen3.5-9B ran with FP8 weights and is reported outside the pre-registered tests.

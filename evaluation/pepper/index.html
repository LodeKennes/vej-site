Pepper Alpha evaluation

ItsVej/pepper-1-alpha-2410 is an alpha checkpoint with a Gemma 4 12B base and a native decision head. Pepper Alpha is free for granted organizations.

Test results

The same frozen r5 test used for Pea contains 14,286 text decisions: 5,000 HelpSteer1 ratings and 9,286 SGD decisions from held-out domains. Pepper was served in production on the Hetzner GPU through the calibrated bridge. This report evaluates 14,070 / 14,286 decisions; 0 are missing and 216 are excluded.

Pea’s published figures use T=1; its hosted API uses T=1.334. Pepper’s figures use production probabilities at T=1.995 (1.9952623149688802 in the record), without a second scaling. Positive scalar temperature scaling preserves the highest-probability outcome. Pea’s calibrated NLL, Brier and ECE cannot be recovered from aggregate figures. Pepper’s restricted subset and Pea’s full test have different coverage; these are not same-row comparisons. These results do not establish general superiority or statistical significance.

Accuracy is exact label accuracy, including exact rubric level for Score. NLL and Brier sum are lower-is-better losses; Brier sums squared errors over outcomes. ECE uses 10 equal-width top-1 confidence bins and is descriptive, not a population guarantee.

Calibration

Fit alone selected one positive scalar temperature using an 81-point logarithmic grid over [0.1, 10], minimizing NLL. Check did not select T. Whole groups matching Pepper checkpoint-selection validation were excluded from the reused Pea calibration sources. All three acceptance gates passed: interior T, lower check NLL and check ECE15 no worse by more than 0.01. These before/after metrics use saved T=1 outputs, separately from the production test collection above.

Limitations

This alpha checkpoint comes from an incomplete training run (selected step 128, before a full pass). Calibration does not improve label accuracy. This is a text-only evaluation, with no image or audio benchmark. The test set was exposed during Pea development; upstream pretraining exposure is unknown. Source/domain-transfer decisions are not end-to-end tool calls or Jev’s proprietary benchmark. These sample metrics provide no population guarantee, factual-accuracy guarantee or instruction-following guarantee.

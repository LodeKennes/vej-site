# Vej website

Public website: https://itsvej.com

Vej builds Pea, Pepper and Pumpkin. Pea is a completed 2B text decision model,
available by request. Pepper (8B) and Pumpkin (27B) are in private development
and unavailable for public use. Only Pea has published evaluation results.

This repository contains the generated website, not model weights or datasets.
The build manifest identifies the source revision. Signup records and contact
messages are stored in a private EU Cloudflare D1 database managed by the
separate infrastructure repo.

Contact: https://itsvej.com/contact/

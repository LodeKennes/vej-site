Architecture

A decision head, not text generation.

Qwen3.5-2B provides the pretrained text backbone. Vej freezes its base BF16 parameters and trains rank-16, alpha-32 LoRA adapters alongside a custom FP32 scalar decision head. There is no vocabulary projection head, token generator, or vision component in this release.

State + question + outcome→Scalar score

State, question, and candidate text are concatenated and passed through the model to produce a scalar score. Candidate scores are normalized into probabilities within each independent question. Choice preserves semantic option names and descriptions. Noul assesses true and false outcomes. Score evaluates rubric levels independently, and application code calculates the zero-based expected score.

Execution mode
Independent candidate batching with repeated state encoding

State encoding is repeated for each candidate outcome. Shared-state reuse remains experimental and is not enabled in this release. No serving latency advantage has been measured. Timings from the earlier DeBERTa alpha1 do not apply to this checkpoint.

Availability

Privately published on Hugging Face.

The checkpoint is hosted at Kennes/vej-qwen-2b-alpha2 on Hugging Face as a private model. Access is restricted to authorized account members. It is not currently a public weight download.

The private package contains the complete native checkpoint, tokenizer assets, matching Vej source code snapshot, model card, dataset documentation, aggregate metrics, licenses, and SHA256 checksums. No raw dataset texts are bundled.

The core development repository at LodeKennes/Vej is also private. This public website is hosted from LodeKennes/vej-site, which contains only website source files and static assets.

Local inference

Run it on your GPU.

Authorized users can download the release package with their authorized Hugging Face account, verify SHA256SUMS, extract vej-source.tar.gz, and run predictions directly from that source directory. Python 3.12 to 3.14 is supported. 

uv sync --frozen --extra cpu --extra qwen
HF_HUB_OFFLINE=1 uv run --frozen --extra cpu --extra qwen python -m vej predict \
  examples/decisions.json --checkpoint /path/to/download/checkpoint --device cpu

CPU execution is a functional fallback and can be slow. The backbone remains BF16; disabling autocast does not convert it to FP32. For compatible CUDA or ROCm environments, install the source package with its qwen extra in your GPU environment, then execute: 

HF_HUB_OFFLINE=1 python -m vej predict examples/decisions.json \
  --checkpoint /path/to/download/checkpoint --device cuda \
  --precision bfloat16 --candidate-batch-size 4

vLLM compatibility

This checkpoint cannot currently run with stock vllm serve. Vej exports a custom native state dict containing the trained FP32 scalar head and LoRA weights rather than a standard causal language model or sequence classification export. Passing --runner pooling does not load these weights.

A compatible export must implement last valid-token readout, support the learned scalar head, preserve exact candidate formatting, and apply question-wise normalization. That integration is not implemented or tested.

vLLM provides pooling interfaces and custom model registration. These are architectural references for future work, not evidence that the current release operates under vLLM (checked 27 September 2026). Use Vej's native loader. Generic PEFT loaders, AutoModelForCausalLM, and hosted inference providers are not supported interfaces.

Known limits.

The final test recorded 76.60% exact accuracy across 14,286 decisions. Score accuracy (51.62%) and tool diagnostics remain weak. Confidence values are descriptive sample metrics, not population calibration guarantees. Type safety and normalized probabilities do not establish factual accuracy, instruction following, or safety to execute tools.

Always place independent application policies around consequential actions. This alpha release makes no claims of autonomous tool safety, production readiness, or general Jev parity. Review the same-test hosted Jev comparison with its documented rounding and exposure constraints.

Architecture

A scorer, not a completion.

Qwen3.5-2B supplies the pretrained text backbone. Vej freezes its BF16 base parameters and trains rank-16, alpha-32 LoRA adapters plus a scalar decision head. There is no vision encoder or vocabulary output head in this checkpoint.

State + question + outcome→Scalar score

Candidate scores become probabilities within each independent question. Choice preserves semantic outcome names and descriptions. Noul uses true/false outcomes. Score assesses described levels independently, then computes the expected zero-based position in ordinary code.

Availability

Privately published.
Self-hostable.

The checkpoint is uploaded to Kennes/vej-qwen-2b-alpha2 on Hugging Face as a private model. Access is limited to authorized account members. It is not a public weight download.

The private package contains the full checkpoint, tokenizer/config assets, matching Vej source snapshot, model and dataset cards, aggregate metrics, licenses and SHA256 checksums. No raw training, validation or test corpus is included.

The main development repository is also private. This public site publishes documentation and brand assets; its website repository contains only the site build.

Local inference

For checkpoint holders.

Download the private release with your authorized Hugging Face account. Verify SHA256SUMS, extract its matching vej-source.tar.gz, and run from that source directory. Python 3.12–3.14 is supported. 

uv sync --frozen --extra cpu --extra qwen
HF_HUB_OFFLINE=1 uv run --frozen --extra cpu --extra qwen python -m vej predict \
  examples/decisions.json --checkpoint /path/to/download/checkpoint --device cpu

CPU is a functional fallback and can be slow. The backbone remains BF16; disabling autocast does not convert it to FP32. For compatible CUDA/ROCm PyTorch, install the source package with its qwen extra in your GPU environment, then: 

HF_HUB_OFFLINE=1 python -m vej predict examples/decisions.json \
  --checkpoint /path/to/download/checkpoint --device cuda \
  --precision bfloat16 --candidate-batch-size 4

vLLM compatibility

This checkpoint cannot currently run with stock vllm serve. Vej saves a custom native state dict, including the trained FP32 scalar head and LoRA weights, rather than a standard causal-LM or sequence-classification export. Selecting --runner pooling does not convert those weights.

A compatible export and native pooling adapter must preserve the last valid-token readout, learned scalar head, exact candidate rendering and question-wise normalization. That integration is not implemented or tested. The native loader commands above are the supported path.

vLLM provides pooling interfaces and custom-model registration; these are integration building blocks, not evidence that the current release works with vLLM. Checked 27 September 2026.

Use Vej’s native loader. This is not an adapter-only download or a text-generation pipeline. Generic PEFT loading, AutoModelForCausalLM and hosted inference providers are not supported interfaces. Dependencies require installation; the bundled model assets need no network access at inference time.

Intended use

Research decision support.

The final test measured 76.60% exact accuracy across 14,286 decisions. Score reliability and tool diagnostics remain weak. Confidence is imperfect. Type safety and normalized probabilities do not establish truth, instruction following, calibrated risk or permission to execute tools.

Use independent policy checks around consequential actions. This release makes no autonomous-tool-safety, production-readiness or general Jev-parity claim. Read the same-test hosted Jev comparison with its rounding and exposure limitations.
